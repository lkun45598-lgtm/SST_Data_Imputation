# 因果逐时序列时空 KNN 预处理 v3 设计

## 目标

创建一套独立的 JAXA 逐时 SST 预处理流程，对每个目标帧严格按因果顺序填充：先使用目标时刻之前 72 小时内同一网格位置的真实观测，对时序填充值执行原有 Gaussian 平滑，再对剩余海洋缺失区域进行结合空间距离和时间距离的时空 KNN 插值。现有预处理脚本、H5 文件、checkpoint 和实验目录均保持不变。

## 范围与非目标

本次包含：

- 使用现有 `h00`--`h23` H5 文件中的 `original_obs_mask`，重建只包含真实观测的逐时帧；
- 基于真实时间戳、严格只看过去、最大回溯 72 小时的时序填充；
- 对时序填充和 Gaussian 平滑后仍然缺失的像素进行时空 KNN 填充；
- 区分原始观测、时序填充、KNN 填充和最终未解析像素的诊断 mask 与统计信息；
- 在完整重算前，先对 Series 8 的 frame 223 及其相邻目标帧进行小规模验证。

本次不包含：

- 修改 `Data_Imputation/preprocessing/hourly_preprocess.py` 或 `knn_fill_3d.py`；
- 修改现有 H5 文件或 checkpoint；
- 在检查新预处理结果之前重新训练 FNO-CBAM；
- 将缺少的时间戳前后两帧强行视为相邻帧。

## 数据来源与时间戳模型

数据源为现有文件：

`Data_Imputation/experiments/hourly_data/h{00..23}/jaxa_knn_filled_{series:02d}.h5`

只有同时满足以下条件的像素才被视为真实观测：`original_obs_mask == 1`、`land_mask == 0` 且 SST 值为有限值。旧流程产生的时序填充值、Gaussian 值和 KNN 值都不能作为真实观测源。

所有帧都按照解码后的 `timestamps` 建立索引，索引键为真实 `datetime`。缺少的小时或日期不出现在索引中，直接跳过。所有权重中的时间差都由真实时间戳计算，不能由数组下标推断。

目标序列从一个配置的小时中选择，默认使用 `h12`，并保留该小时实际存在的目标时间戳。处理开始前需要检查不同小时文件的空间尺寸和必要字段是否一致。现有逐时 H5 的 `land_mask` 在少量海岸像素上存在文件间差异，因此采用所有源文件陆地掩码的保守并集；并集内像素始终按陆地处理，不参与插值，并在输出中保持 NaN。

## 阶段 1：因果同位置时序填充

对于每一个目标时刻 `t`：

1. 以目标帧的原始观测作为初始值，其余海洋像素设为 NaN；
2. 查找真实时间戳为 `t - delta` 的历史帧，其中 `delta` 为 `[1, 72]` 小时内的整数。未来帧永远不能使用；
3. 对当前仍缺失的每个海洋像素，只收集历史帧中相同 `(y, x)` 网格位置的有限真实观测；
4. 使用按实际时间差衰减的加权平均进行填充：

   `w(delta) = 1 / delta`

如果 72 小时内同一位置没有任何可用真实观测，则该像素继续保持 NaN，留给阶段 2 处理。

原始观测值不可被覆盖。`temporal_fill_mask` 标记本阶段新填充的像素。实现时应在空间网格上进行向量化累加，不能对每个缺失像素使用低效的 Python 逐点循环。

## 阶段 1.5：对时序填充值进行 Gaussian 平滑

时序填充完成后，执行现有预处理流程中的 Gaussian 平滑，默认 `sigma = 1.5`。平滑规则保持不变：

- 卷积输入使用当前帧中原始观测和时序填充值组成的有限值；
- 对卷积输入中的无效像素使用当前帧有限值的均值作为临时填充值，避免 NaN 传播；
- Gaussian 结果只写回 `temporal_fill_mask == 1` 的像素；
- 原始观测像素保持原值，不被平滑结果覆盖；
- 时序填充后仍为 NaN 的像素保持 NaN，不被 Gaussian 阶段填充。

该阶段只用于平滑时序插值产生的局部突变，不会直接填补自然缺失区域。Gaussian 完成后，仍然缺失的像素进入阶段 2。

## 阶段 2：因果时空 KNN 填充

阶段 2 只处理阶段 1 和阶段 1.5 后仍缺失的海洋像素。固定候选池包括：

- 当前目标帧的原始观测，时间差记为 `delta = 0`，可靠性为 1；
- 当前目标帧阶段 1 的时序填充值，时间差记为 `delta = 0`，但使用较低可靠性；
- `(t - 72 h, t)` 内所有实际存在的历史时间戳对应帧中的原始观测，每个候选携带其真实 `delta`。

历史帧中的阶段 1 填充值和所有历史 KNN 填充值都不能进入候选池。这样可以防止合成值递归成为后续帧的输入证据。

对每个待填充像素，先根据空间距离搜索候选，再结合真实时间差进行排序。实现采用每个有效历史源帧上的二维空间邻域搜索，并使用如下可分离权重合并候选：

`w = reliability * (distance_space + eps)^(-p_space) * (1 + delta_hours)^(-p_time)`

默认参数为 `p_space = 2`、`p_time = 1`。同一空间位置的历史观测会具有最高的空间权重；在正常情况下，它们已经在阶段 1 被优先用于同位置时序填充。阶段 1 填充值使用较低可靠性，避免合成值压过原始观测。

阶段 1 可靠性默认设为 `0.5`。每个源帧最多搜索 8 个空间邻居，然后对每个目标像素保留综合权重最高的 20 个候选。所有这些参数都必须显式记录，以便小规模实验可以复现。

同一个目标帧首先使用原始观测、Gaussian 后的时序填充值和历史真实观测作为 KNN 种子。随后允许采用正常的渐进式 2D KNN：当前目标帧中新生成的 KNN 值可以继续作为同一帧后续缺失像素的空间邻居，从而完成大面积缺口的填充。新生成的值只能在当前目标帧内部使用，绝不能写入历史候选池，也不能被后续时间帧当作真实观测。

只要当前帧或过去 72 小时内存在至少一个有效海洋候选，渐进式 KNN 就应当将该目标帧的海洋缺失区域全部填完。若当前帧和过去 72 小时完全没有任何有效候选，这不是正常插值分支，而是输入数据异常；程序必须报告具体时间戳并停止写入该结果，不能保存带有未处理 NaN 的 H5，也不能静默使用全局均值。

v3 默认启用上述 Gaussian 阶段，使用原有 `sigma=1.5` 的处理方式。以后如需进行去 Gaussian 消融，只能作为显式可选开关，不得改变默认数据处理流程。

## 输出与隔离

输出写入新的版本目录，例如：

`Data_Imputation/experiments/hourly_data_v3_temporal72/h12/`

文件名保持与现有 dataset loader 兼容。每个输出 H5 除现有必需字段外，还应包含：

- `temporal_fill_mask`；
- `knn_fill_mask`；
- `unresolved_mask`；
- 从目标序列复制的 `timestamps`。

为兼容当前训练代码：

- `original_obs_mask` 表示不可变的原始真实观测区域；
- `original_missing_mask` 表示阶段 1 时序填充后、阶段 1.5 Gaussian 平滑和阶段 2 KNN 之前仍然存在的自然缺口；
- `temporal_fill_mask` 表示阶段 1 填充的像素；
- `knn_fill_mask` 表示阶段 2 填充的像素；
- `unresolved_mask` 表示两阶段之后仍为 NaN 的海洋像素。

这样，现有 dataset 会继续把“时序填充和 Gaussian 平滑后仍缺失的区域”作为 natural reconstruction 区域。文件属性需要记录版本号、目标小时、时间窗口、Gaussian sigma、权重参数、真实观测筛选规则以及最终未解析海洋像素数量。输出程序拒绝覆盖非空目录。

## 验证流程

验证按由小到大的范围进行：

1. 使用合成帧编写单元测试，验证严格因果性、72 小时边界、时间戳断档、同位置时序填充、Gaussian 只修改时序填充值、原始观测不可变，以及 KNN 候选中不存在递归合成值；
2. 使用所有可用逐时源文件，对 Series 8 的 frame 223 及相邻目标帧进行 smoke run，输出时序填充覆盖率、KNN 填充覆盖率、未解析覆盖率、候选时间差分布，以及观测区到填充区接口处的梯度统计；
3. 在新的诊断目录中生成新旧结果并排可视化，不修改现有图片和缓存；
4. 只有 smoke run 结果可接受后，才生成完整目标序列。模型重新训练属于后续独立步骤。

## 风险与对应措施

- **源数据时间不规则：** 使用真实时间戳索引，报告缺少的历史小时，绝不根据数组下标推断相邻关系；
- **合成值污染：** 只使用 `original_obs_mask` 选取源像素，不读取历史帧的填充值作为真实证据；
- **候选池过大：** 缓存 H5 元数据和空间搜索结构，按批处理缺失像素，并先进行 frame 223 的 smoke run；
- **残余 NaN：** `unresolved_mask` 只作为审计字段，正常输出中应全部为 0；如果出现非零像素，程序报告对应时间戳并拒绝生成可用于训练的结果。
