# OSTIA 预训练与 JAXA 适配的观测约束 EDM 设计

## 状态与决策

本文档定义一个不依赖时间插值、KNN 或高斯代理场的 SST 缺失重建实验。
用户已经确认采用以下主路线：

1. 在完整 OSTIA 日场上训练像素空间 EDM SST 先验；
2. 在 JAXA 上通过人工目标掩码进行自监督条件适配；
3. 推理时以当前 JAXA 真实观测为硬约束，只生成自然云缺失区域；
4. 在 A100 服务器上训练，代码和中间产物与现有 FNO、STIMP 实验隔离。

这里的“完整 OSTIA 场”是经过现有 OSTIA 数据处理流程得到的分析场参考，
不是逐像素现场观测真值。它用于学习 SST 空间分布先验，不与 JAXA 小时场
做逐时配对。

## 目标

- 验证完整场扩散先验能否在没有代理场的条件下重建大面积 SST 缺口。
- 保留当前 JAXA 真实观测，不让模型修改已观测像素。
- 在人工遮挡且有真值的区域定量验证温度误差、梯度、频谱和边界连续性。
- 在自然云区输出集合均值和集合离散度，不把无真值区域的结果表述为唯一真值。
- 仅在第一阶段通过后引入 48 小时 JAXA 历史条件，避免混淆空间先验与时间条件的作用。

## 不在本次范围内的内容

- 不使用 OSTIA 场与 JAXA 小时场逐时配对。
- 不把 OSTIA 同日期场作为 JAXA 当前小时的显式背景。
- 不把时间插值、二维或三维 KNN、OI、高斯平滑结果用作输入代理或训练标签。
- 不在自然云缺失像素上计算有监督损失。
- 不修改或覆盖现有 FNO-CBAM、STIMP、代理场数据、论文缓存或 checkpoint。
- 不使用潜空间扩散；第一版必须在原 SST 网格的像素空间生成。
- 不把一次自然云区可视化作为精度证明。

## 选择 EDM 的依据

主模型采用 Karras EDM 预条件化的连续噪声扩散模型，去噪器采用适合中等规模
科学场数据的 NCSN++/ADM 风格二维 U-Net。它比本项目中的其他候选更符合当前约束：

- 相比固定 50 或 1000 步 DDPM，EDM 的连续噪声训练和 Karras 采样在较少
  采样步下更稳定；
- 相比 DiT，卷积 U-Net 对 7,882 张训练场的数据量要求更低，并保留明确的
  多尺度空间归纳偏置；
- 相比潜空间扩散，像素空间 EDM 不引入可能抹平锋面和局地梯度的自编码器；
- 相比现有 STIMP，OSTIA 阶段直接学习完整场分布，而不是仅从稀疏 JAXA
  条件学习自然云区的无监督输出。

“最适合”是基于数据规模、分辨率、缺失形态和训练监督条件作出的工程选择，
最终优劣仍以统一遮挡协议下的验证结果为准。

## 数据契约

### OSTIA

远端 A100 已存在以下只读输入目录：

`/home/lz/sst_data/sst_missing_value_imputation/processed_data`

三个 HDF5 split 为：

| Split | 帧数 | 起止日期 |
|---|---:|---|
| train | 7,882 | 1991-01-01 至 2012-07-30 |
| valid | 1,689 | 2012-07-31 至 2017-05-16 |
| test | 1,690 | 2017-05-17 至 2021-12-31 |

每帧网格为 `451 x 351`。训练只读取：

- `ground_truth_sst`：完整 SST 参考场；
- `land_mask`：静态海陆掩码；
- `latitude`、`longitude`：静态坐标；
- `time_iso`：年内日期条件；
- `effective_cloud_mask`：只用于验证和测试阶段的重建遮挡，不参与完整场先验训练。

禁止读取 `input_sst` 作为 EDM 输入。该字段包含现有线性/最近邻补值，与本实验的
无代理目标冲突。

OSTIA 序列中的日期断档不跨帧拼接。第一阶段模型是单时刻二维空间先验，各帧
独立采样，因此日期断档不产生伪相邻关系。

### JAXA

JAXA 使用原始逐小时 SST、原始观测掩码和静态海陆掩码。允许复用现有 STIMP
正式数据缓存中的原始观测值和索引，但加载器必须检查缓存来源，不得读取任何
时间、KNN、OI 或高斯填充值。

数据划分保持既定年度序列协议：

- 训练：Series 0--6；
- 验证：Series 7；
- 测试：Series 8。

每个目标样本使用目标时刻及其之前最多 48 个真实小时时隙。时隙按时间戳建立，
不得将缺文件后的下一帧压缩为相邻小时，不得跨年度序列边界。缺文件或自然云像素
仅表示“未观测”，其数值占位不具有 SST 语义。

### 归一化

OSTIA 训练集海洋像素计算一组固定均值和标准差，验证、测试及首次 JAXA 后验
重建均使用同一组参数。JAXA 观测保持 Kelvin 物理值，按 OSTIA 参数归一化后进入
观测算子。任何 JAXA 域偏差由后续条件适配处理，不能通过自然云区伪标签校正。

## 模型设计

### 空间 EDM 先验

干净归一化 SST 记为 `x0`。训练时从对数正态噪声分布采样 `sigma`，构造
`x_sigma = x0 + sigma * epsilon`，去噪器输出预条件化的干净场估计。初始配置为：

- `sigma_data = 1.0`；
- `P_mean = -1.2`，`P_std = 1.2`；
- 采样 `sigma_min = 0.002`，`sigma_max = 80`，Karras `rho = 7`；
- EDM 加权去噪 MSE，只在海洋像素计算；
- 不额外加入梯度或频谱训练损失，以免破坏第一版 score 的概率语义。

去噪 U-Net 使用：

- 基础通道 96，通道倍数 `[1, 2, 3, 4]`；
- 每个尺度两个残差块，GroupNorm、SiLU 和 0.1 dropout；
- Fourier 噪声级嵌入；
- 在最小的两个空间尺度注入日历条件，在最小尺度使用全局自注意力；
- 输入静态海洋 mask、归一化纬度和经度坐标，显式表示固定地理位置；
- 使用年内日期正余弦条件，不使用 OSTIA 小时条件。

原始网格使用常量无效区 padding 到 `464 x 352`，同时 padding 海陆 mask 和坐标。
padding 像素不参加损失，输出严格裁回 `451 x 351`。禁止缩放到更低输出分辨率。

### JAXA 条件适配器

OSTIA 先验通过第一阶段验收后，增加一个独立的 JAXA 条件分支：

- 共享二维编码器逐帧处理 `[观测 SST, 观测 mask, 与目标时刻的时间差]`；
- 输入目标时刻及之前最多 48 个真实小时时隙；
- 在下采样特征上沿时间维执行注意力；
- 将当前观测、历史条件、小时编码和年内日期编码通过零初始化残差适配层注入
  EDM U-Net 的中低分辨率层；
- 适配器初始为零影响，未训练时模型行为等同于 OSTIA 空间先验。

第一轮适配冻结 EDM-U-Net 和 EMA 主干，只训练历史编码器、条件适配层和条件输出头。
若 Series 7 固定人工遮挡验证不提升，则停止该路线并报告结果；若有稳定提升，再以
主干学习率为适配器学习率的 1/20 解冻最末两个解码尺度。禁止未经验证直接全量解冻。

## JAXA 自监督目标

对目标小时定义：

- `O`：原始真实可见海洋像素；
- `A`：仅从 `O` 中选择的人工云状目标掩码；
- `C = O & ~A`：条件观测像素；
- `N`：原始自然云缺失海洋像素。

人工掩码来自训练 Series 0--6 的真实云形状，并与目标帧 `O` 相交。训练日志记录
nominal level、相交后的 realized fraction 和有效目标像素数。空目标样本必须重采样。

JAXA 适配采用 CSDI 式 masked diffusion 目标：

1. `C` 中输入真实当前观测并由 mask 标识为条件；
2. `A` 中对真实 SST 加入当前扩散噪声，并计算噪声/干净值去噪目标；
3. `N` 中没有真值，只作为未知状态参与采样，不计算监督损失；
4. 损失支持域严格等于 `A`，排除 `C`、`N` 和陆地；
5. 过去 48 小时只使用原始真实观测及其 mask，不使用历史重建值递推。

该目标使 JAXA 适配学习“从剩余观测恢复被人工遮挡的真实值”，同时避免将自然
缺失区的插值结果当作标签。

## 后验重建与观测一致性

### OSTIA 验证

在完整验证场上应用 `effective_cloud_mask`，将未遮挡海洋像素作为观测，遮挡区域
作为待重建目标。从 EDM 噪声状态开始，使用 24 步 Karras sigma 序列和二阶 Heun
更新。每个噪声级都把已观测值转换到匹配噪声级后重新注入，使用 RePaint 式
观测一致性；最终输出在观测位置精确替换为原始观测。

初次定量验证每个案例生成 4 个独立样本，主重建使用集合均值，同时保存逐像素
集合标准差。模型选择不能只依据单张随机样本。

### JAXA 推理

当前 JAXA 真实观测通过同一观测算子进入每个反向扩散步骤。最终组合为：

`reconstruction = observed_sst` 在 `O` 上，扩散集合均值在 `N` 上。

陆地保持无效。任何推理输出若修改 `O`、产生海洋 NaN/Inf、或未保存集合离散度，
均视为失败。自然云区没有像素真值，必须标注为后验重建，不报告无依据的 MAE。

## 训练配置

OSTIA 第一阶段初始正式配置为：

- 8 卡 A100 80 GB DDP；
- BF16 autocast；
- 每卡 batch size 4，全局 batch size 32；
- AdamW，学习率 `2e-4`，梯度裁剪 1.0；
- EMA decay `0.9999`；
- 最多 100 epochs，验证指标 15 epochs 无提升则早停；
- 每轮在全部 OSTIA valid 上计算去噪损失；
- 每 5 轮在固定 96 个遮挡案例上计算 4 成员后验重建指标；
- checkpoint 只保留 `best_ema`、`last` 和一个可恢复优化器状态，不保留逐轮模型。

在正式 DDP 训练前只执行一个有界显存和数值 gate：单卡一次前向/反向、两卡一次
DDP 更新、一个 4 步采样。该 gate 只验证执行完整性，不以 smoke 输出判断效果。
若每卡 batch size 4 超出显存，保持模型和分辨率不变，使用梯度累积维持全局 batch
size 32；不能静默减小网络或分辨率。

## 评价协议

OSTIA valid/test 的遮挡目标有完整参考，统一报告：

- MAE、RMSE 和 Bias；
- Gradient MAE 和梯度相关系数；
- 云区内部空间功率谱差异或分频段能量误差；
- 观测--重建边界的梯度跳变量；
- 低、中、高 realized extra-mask level 分层结果；
- 集合标准差及其与绝对误差的关系。

SSIM 只作为辅助结果，不作为主要结构结论。主模型至少与相同案例上的现有
线性/KNN 输入、OI 和旧 FNO-CBAM 比较。比较必须共享目标 mask、参考场、海陆 mask
和物理单位。

最终全量 OSTIA test 评估只在训练和超参数选择完成后执行一次。JAXA Series 8
只在所有设计选择冻结后使用；Series 7 用于 JAXA 条件适配和停止判断。

## 验收与停止条件

第一阶段 OSTIA EDM 必须同时满足：

1. 有效海洋输出全部有限，陆地与 padding 不参与损失；
2. 最终组合逐像素精确保留观测值；
3. 固定遮挡验证的集合均值优于无条件气候均值，并至少不劣于现有 OI/KNN 的
   MAE 与边界跳变量；
4. 可视化不存在成片恒值、明显网格条纹或陆海泄漏；
5. 训练日志、配置、归一化参数、数据 split 和随机种子可追溯。

若第一阶段未通过，不启动 JAXA 微调，也不通过增加网络规模掩盖数据或采样问题。
先诊断先验训练、归一化和后验采样。

JAXA 适配必须在 Series 7 固定人工遮挡集合上，相比仅 OSTIA 先验至少改善一个
点误差指标和一个结构指标，且其他主指标无明显退化，才进入 Series 8 与自然云区
可视化。若没有稳定提升，保留 OSTIA 后验基线并终止适配路线。

## 实现顺序

1. 建立隔离工作树和新模块，不复制现有 STIMP 的训练语义。
2. 实现 OSTIA 完整场数据集、归一化统计和静态条件。
3. 实现 EDM 预条件、U-Net、EMA、Karras-Heun 采样和观测一致性。
4. 完成数值/DDP gate 后在 A100 启动 OSTIA 正式训练。
5. 完成 OSTIA fixed-mask 和全量 test 评价，审查是否达到进入 JAXA 的门槛。
6. 仅在门槛通过后实现并训练 48 小时 JAXA 条件适配器。
7. 冻结设计后评估 Series 8，并生成自然云区集合均值和不确定性可视化。
