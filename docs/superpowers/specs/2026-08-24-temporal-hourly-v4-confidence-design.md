# 因果逐小时置信度代理重建 v4 设计

## 目标

为 JAXA 逐小时 SST 构建一套独立的、严格因果的全量代理重建流程。该流程需要在连续重云条件下继承可信的历史空间结构，同时避免旧版 3D KNN 将历史合成值直接等同于真实观测而递归放大偏差或伪影。

本版本处理全部 9 个年度序列和全部 `h00`--`h23` 小时产品。每个已完成小时既保存到磁盘，也作为后续至多 72 小时的因果历史。已有 `hourly_preprocess.py`、`knn_fill_3d.py`、旧 H5、v3 输出、checkpoint 和论文结果均不修改。

## 输入、时间与隔离

- 输入根目录：`Data_Imputation/experiments/hourly_data`。
- 每个源像素仅在 `original_obs_mask == 1`、非陆地且 SST 有限时被视为真实观测。
- 所有历史关系由解析后的真实 `timestamps` 建立，不能由帧下标推断；不存在的小时或日期直接跳过。
- 每个年度序列独立重建，序列间不传递历史。每个序列内部按真实时间戳从早到晚严格串行。
- 各小时源文件的陆地掩码采用保守并集；任一源文件标为陆地的像素始终保持 NaN，不参与插值或评估。
- 新代码放在 `Data_Imputation/preprocessing/temporal_hourly_v4/`，不修改 v3 或旧版代码。

## 每帧重建流程

对于目标时刻 `t`，依次执行以下阶段。

### 1. 原始观测与同位置时序填充

目标帧真实观测值不可修改。对其余海洋缺失像素，只收集 `t-72h` 至 `t-1h` 内同一网格位置的真实观测，按实际时间差 `delta` 使用 `w_t(delta) = 1 / delta` 加权平均。历史代理值在本阶段一律不参与。

这保证同一位置的最近真实观测优先于任何合成值，并使数据断档不会被错误地视为连续时间。

### 2. 时序填充值 Gaussian 平滑

沿用旧处理流程的 `sigma = 1.5` Gaussian 操作，但只写回本阶段新增的时间填充值。原始观测、陆地和仍缺失的海洋像素都保持不变。该步骤只减轻时间插值的局地离散跳变，不直接填补自然缺失区。

### 3. 残余缺失区的基础估计

仅对阶段 1--2 后仍缺失的海洋像素进行填充。候选包括：

- 当前帧的真实观测；
- 当前帧的时序填充值；
- 过去 72 小时内的真实观测。

候选权重同时考虑来源置信度、空间距离和真实时间差：

`q = c * (d_space + 1)^(-2) * exp(-delta_hours / 24)`。

当前帧候选的时间差为 0。当前帧的渐进式 2D KNN 仍从缺失边缘向内重建，并可将本帧较早生成的值作为本帧后续批次的空间邻居。为避免在 451 x 351 网格上频繁重建 KDTree，默认每 500 个缺失像素重建一次；该批之前新生成的值不会被同批引用。此行为只用于完成当前帧，不能使其自动成为未来帧的真实证据。

### 4. 可信历史代理结构的受控混合

过去 72 小时已重建帧中的 `temporal` 和 `KNN` 像素可为阶段 3 的残余区提供局部结构信息，但必须同时满足：

- 保存的置信度不低于 `0.20`；
- 历史合成值与查询点的空间距离大于 0，禁止零空间距离的直接复制；
- 候选使用上述时间、空间和置信度衰减。

对同一像素分别计算基础估计 `B` 和历史代理结构估计 `P`。最终只在残余缺失区混合：

`F = (1 - alpha) * B + alpha * P`。

对任一候选集合 `S`，令 `q_i` 为阶段 3 的候选权重，计算：

- `C_S = sum(q_i * c_i) / sum(q_i)`；
- `D_S = sum(q_i * d_i) / sum(q_i)`；
- `T_S = sum(q_i * delta_i) / sum(q_i)`；
- `N_S = sum(q_i)^2 / sum(q_i^2)`；
- `R_S = C_S * exp(-D_S / 20) * exp(-T_S / 24) * (1 - exp(-N_S / 4))`。

`R_B` 和 `R_P` 分别为基础候选与代理候选的局部证据强度。定义 `alpha = 0.65 * R_P * (1 - R_B)`。因此，在当前帧观测充分时代理结构几乎不改变基础估计；在持续重云且存在可信历史结构时，代理可以补充但不完全替代当前证据。

历史代理与当前温度水平的偏差只允许由查询点附近的当前真实锚点估计：半径 48 像素内至少 5 个真实锚点时，使用稳健中位数局地偏差校正；不足时偏差设为 0。流程禁止旧版那种在当前观测过少时依赖全局帧均值的无条件偏差校正。

若基础候选不存在而可信历史代理存在，则以代理估计作为当前帧的插值种子；若两者都不存在，程序报告具体时间戳并拒绝生成可用于训练的结果，绝不静默使用全局均值或保存海洋 NaN。

## 来源与置信度

每个海洋像素保存离散来源码和 `[0, 1]` 置信度：

| 来源 | 来源码 | 置信度规则 |
| --- | ---: | --- |
| 真实观测 | `1` (`raw`) | 固定为 `1.0` |
| 同位置时间填充 | `2` (`temporal`) | `0.85 * (1 - exp(-n_eff / 2)) * exp(-delta_effective / 24)` |
| 残余 KNN 填充 | `3` (`knn`) | `min(0.75, (1 - alpha) * R_B + alpha * R_P)` |
| 陆地/未解析 | `0` / `4` | 陆地为 `0`；未解析属于异常并拒绝生成训练输出 |

其中，`n_eff = sum(w_t)^2 / sum(w_t^2)` 是时间权重对应的有效历史样本数，`delta_effective = sum(w_t * delta) / sum(w_t)` 是按时间权重计算的有效时间差。该设定使单个 `t-1h` 真实观测的初始置信度约为 `0.32`，多个近时真实观测可形成更高置信度，而稀少且久远的样本不会在未来持续传播。

最终所有海洋像素必须在当前帧得到数值。低于 `0.20` 的 KNN 值保留在该帧输出中以完成空间场，但不进入未来帧的历史代理池。代理置信度永远不能被提升为真实观测置信度。

## 并行与存储

时间因果依赖禁止在同一年度序列的时间轴上并行。9 个年度序列可独立并行运行；每个序列的批量 `cKDTree.query` 使用 21 个 worker，共 `9 x 21 = 189` 个 CPU worker。设置 BLAS/OpenMP 为单线程，避免与 KDTree worker 叠加造成过度订阅；剩余 CPU 留给 HDF5 I/O、压缩和调度。

每个序列只在内存维护过去 72 小时的重建帧、来源码和置信度，不加载全量数据。

输出根目录固定为：

`/data/sst_data/sst_missing_value_imputation/jaxa_processed_data/`

目录和文件形式与既有 `Data_Imputation/experiments/hourly_data/` 完全一致，不额外套版本目录：

```text
jaxa_processed_data/
  h00/jaxa_knn_filled_00.h5 ... jaxa_knn_filled_08.h5
  h01/jaxa_knn_filled_00.h5 ... jaxa_knn_filled_08.h5
  ...
  h23/jaxa_knn_filled_00.h5 ... jaxa_knn_filled_08.h5
  diagnostics/
```

每个 H5 保持旧格式已有字段及数据类型：`sst_data`（`float32`、gzip）、`land_mask`（`uint8`、gzip）、`latitude`、`longitude`、`original_obs_mask`（`uint8`、gzip）、`original_missing_mask`（`uint8`、gzip）、`temporal_fill_mask`（`uint8`、gzip）和 `timestamps`（`S32`）。同时保留兼容属性 `creation_date`、`hour_offset`、`num_frames` 和 `series_id`。

在不改变旧 loader 读取行为的前提下，v4 额外追加：

- `knn_fill_mask`、`unresolved_mask`：`uint8`、gzip 的审计掩码；
- `source_code`：`uint8`、gzip 的像素来源码；
- `proxy_confidence`：`float16`、gzip 的置信度图；
- v4 专用文件属性：版本、窗口、平滑参数、时间/空间权重、混合上限、代理阈值与来源政策。

根输出目录若已存在任何 `hXX` 目录或目标 H5，程序必须拒绝写入，避免覆盖已有数据。每个序列生成逐帧诊断 CSV/JSON，记录原始、时序、KNN 覆盖率，代理混合权重统计，进入历史池的覆盖率、平均置信度以及未解析像素数。

## 验证门槛

全量运行前必须完成以下验证：

1. 单元测试：无未来泄漏、真实时间断档、原始观测不变、Gaussian 仅作用于 temporal、低置信度不传播、历史合成值不零距离复制，以及无有效候选时显式失败。
2. 因果 smoke run：Series 8 从年初顺序重建至连续重云目标时刻，确保其 72 小时历史真实可用；不能只孤立计算目标帧。
3. 诊断比较：在同一色标下比较旧版、v3 与 v4 的原始观测、时间填充、Gaussian、最终填充四联图，检查观测--重建边界处梯度跳变和填充区梯度分布。
4. 合成 extra-mask 验证：仅在被遮挡且原始真值存在的区域计算 MAE、Gradient MAE、梯度相关性和 SSIM。v4 需要在数值误差不显著恶化的前提下，减少接口梯度跳变并恢复更多合理的中尺度梯度。
5. 先对一个完整年度执行吞吐量基准，再根据实测耗时估计全量运行时间。未通过上述检查不得启动全量生成。

## 非目标

- 不在该步骤训练或重训练 FNO-CBAM；
- 不修改旧的代理输出、模型 checkpoint、论文图表或缓存；
- 不将缺失日期两侧的帧当作连续时间；
- 不用全局平均值填充无候选海洋像素；
- 不将历史合成值伪装为真实观测。
